# 对话回复语言

在对话框中回复用户时**一律使用中文**,不要用英文或其他语言作答。

- 此约束只针对**对话回复**(给用户看的对话文字):解释、汇报、追问、总结等,全部用中文。
- **不改变代码书写**:代码标识符、第三方库/专有名词按各自生态惯例保持原文;界面上用户可见的文案走 i18n 的 `t()`(见 `i18n` 技能)。
- 无法用 ESLint 静态强制(约束的是对话而非代码),始终自觉遵守。
